# Llapi Fert

Website informues front-end për kompaninë Llapi Fert, prodhuese të gypave të betonit dhe fertrajve për shtëpi.

## Teknologjitë

- **HTML5** për strukturën dhe përmbajtjen e faqeve.
- **CSS3** për dizajnin, animacionet dhe përshtatjen në kompjuter e telefona.
- **JavaScript** për menynë mobile, galerinë interaktive dhe dërgimin e formularit të kontaktit.
- **EmailJS** për dërgimin e mesazheve nga formulari.

Faqja përfshin informata për kompaninë, produktet, galerinë e fotografive, kontaktin dhe lokacionin.
